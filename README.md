## 📥 Quick Start Guide

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vikasingh0897/OPPs-Lab-Program.git

cd OPPs-Lab-Program
```

### 2️⃣ Compile a Single Program

```bash
# Using g++ with C++11 standard
g++ -std=c++11 lab1.cpp -o lab1

# Or with additional flags
g++ -std=c++11 -Wall -g lab1.cpp -o lab1
```

### 3️⃣ Run the Program

**Linux/Mac:**

```bash
./lab1
```

**Windows (PowerShell):**

```powershell
.\lab1.exe
```

**Windows (Command Prompt):**

```cmd
lab1.exe
```
